# MAGE（SNOWSKY MAGE）USB 协议与按键实测笔记

实测设备：SNOWSKY MAGE（型号 F5101K），VID = 0x2972（FIIO），序列号 000000000000。
所有结论均在本机实测验证（2026-11-13）。

## 1. USB 枚举特性

- **PID 随 7.1 开关变化**：
  - `0x4022`（16418）= 7.1 关闭（2 声道模式）
  - `0x4026`（16422）= 7.1 开启（8 声道模式）
  - 切换 7.1 会通过厂商命令触发设备 USB 重新枚举。
- 用户补充（2026-11-13）：音乐模式切到游戏模式，以及 7.1 开启、关闭时设备会重启；游戏切回音乐是否同样重启待核实。两次独立测试均观测到开启 7.1 后正常重枚举为 `0x4026`，关闭命令只发送一次后 `0x4026` 因 `hardware connection lost` 移除，但至少 20–40 秒内没有重新枚举。该异常根因仍未确定，不能把预期重启当作恢复成功；切换完成须等待设备重新枚举、通道可用、音频输入/输出恢复并读回实际状态。USB 位置和 PID 仅用于当前观测，不作为永久设备身份。
- 音频设备有两个：输出（2ch 模式支持 44.1k–384k；7.1 模式仅 48k）、输入/麦克风（固定 48k）。
- 匹配设备建议用 **VID + 产品名 "SNOWSKY MAGE"**，不要写死 PID。

## 2. HID 接口（仅 1 个，复合报表）

Report Descriptor（74 字节）：

```
05 0C 09 01 A1 01          ; Consumer 应用集合
85 03                      ;   Report ID 0x03
... 09 E9 09 EA 81 02      ;   音量+ / 音量-
... 09 CD 09 CF 81 02      ;   播放暂停 / 麦克风静音(定义了但实测不发)
06 01 FF 85 4B             ;   Usage Page 0xFF01（厂商），Report ID 0x4B
75 08 95 3F 09 01 81 03    ;   输入 63 字节
95 3F 09 02 91 02          ;   输出 63 字节
85 07                      ;   Report ID 0x07
75 08 95 3F 09 03 81 03    ;   输入 63 字节
95 3F 09 04 91 02          ;   输出 63 字节
C0
```

注意：描述符里**没有**键盘页，也没有上一曲/下一曲（0xB5/0xB6）。

## 3. 按键实测映射

| 物理按键 | 标准 HID 事件 | 备注 |
|---|---|---|
| 右键 | Consumer 0xE9（音量+） | 干净单发 |
| 左键 | Consumer 0xEA（音量-） | 干净单发 |
| Menu（M 键）短按 | Consumer 0xCD（播放/暂停） | 干净单发 |
| 上键 | Consumer 0xCD | 按住时 10Hz 连发，快按单发；macOS 上成对抵消所以"没反应" |
| 下键 | Consumer 0xCD | 同上 |
| 麦克风键 | **标准通道无任何事件** | 设备本地处理；状态变化通过厂商通道 cmd 18 推送 |

按键事件在 Report ID 0x03 的 1 字节里（bit0=音量+, bit1=音量-, bit2=播放暂停, bit3=麦克风静音）。

## 4. 厂商控制协议（Report ID 0x07）

逆向自 FIIO Control 网页版（fiiocontrol.fiio.com 的 JS bundle），已实测可用。

### 帧格式

```
[HEAD][START][seqHi][seqLo][cmd][len][payload...][crc8][0xEE]
HEAD:  0xAA=设置 / 0xBB=查询
START: 0x0A / 0x0B
crc8:  t=0; for b in bytes: t = table[(t^b)&255]  （256 字节自定义表，见 MageLed.swift）
```

设备的回包 seq 是它自己的计数器，不回显主机 seq。

### 命令表（全量扫描实测，cmd 0–80 逐一查询）

| cmd | 名称 | 回包数据（实测） | 说明 |
|---|---|---|---|
| 1 | VOL_MAX | 120 | 最大音量 |
| 2 | VOL_OUTPUT | 67 | 设备输出音量。**SET 无效**（实测发 80/67 读回不变），MAGE 音量由十字键控制 |
| 3 | 未知 | 148 | — |
| 6 | LED_LIGHT | 1 | 指示灯总开关。**SET 有效（已实测全灭/恢复）** |
| 7 | VOL_BALANCE | 0 | 左右平衡 |
| 9 | 未知 | 2 | — |
| 11 | 未知 | 01 02 00 | — |
| 12 | 未知 | 0 | — |
| 18 | MIC_SWITCH | 1 | 麦克风开关。**SET 有效**；按键后设备主动推送 |
| 19 | 未知 | 01 1E EE EE 00… | 疑似固件版本串 |
| 21 | PEQ_PARAMS | 09 00 00 00 00 00 00 00 | EQ 参数 |
| 22 | PEQ_PRE | 0xF0=240 | 当前 EQ 预设（网页版预设值域 0–260+） |
| 23 | 未知 | 0 | — |
| 24 | 未知 | 10 | 疑似 EQ 段数 |
| 26 | PEQ_SWITCH | 1 | EQ 开关 |
| 32 | 未知 | 1 | — |
| 34 | MIC_VOL | 100 | 麦克风音量。**SET 实测未生效**（读回恒 100，可能需麦克风流激活时设置） |
| 49 | DEVICE_NAME | "SNOWSKY MAGE" | 设备名字符串 |
| 52 | MIC_NR_LEVEL | 100 | 麦克风降噪等级 |
| 53 | GAIN_3D | 10 | 3D 增益 |
| 54 | REVERB_LEVEL | 0 | 混响等级 |
| 55 | CHANNEL71_CONFIG | 16 字节 = 8 声道 × int16 增益 | 7.1 各声道增益（fl fr fc lfe sl sr rl rr） |
| 56 | CHANNEL71_SWITCH | 0 | 7.1 开关。**SET 有效（已实测，设备重新枚举）** |
| 58 | CHANNEL71_GAIN | 0 | 7.1 总增益 |

`cmd 56` 的 SET 写入不代表切换完成。App 必须在同一个厂商通道事务中只写一次并关闭旧 HID 句柄，再等待精确的 MAGE HID 重新枚举、读回目标状态，并确认同名且 alive 的音频输入/输出 stream 与有效采样率。恢复 deadline 会限制 sleep 和厂商请求；不可取消的 IOKit open/close 若由系统阻塞，界面保持“重启重连中”，返回后不得接受超过 deadline 的迟到成功。

**无响应（设备不支持）**：0, 4, 5, 8, 10, 13–17, 20, 25, 27–33, 35–47, 50, 51, 57, 59–160（81–160 已补扫，全部无响应）。
其中 **51 (LED_CTRL RGB 控灯) 无响应**——确认 MAGE 固件不支持任意颜色控制。
29/30 (MIC_MONITOR) 无响应——与网页版功能标记一致（MAGE 不支持监听）。
命令空间到 160 为止，**没有独立的游戏/音乐模式切换命令**（设备上的长按切换是固件本地行为，
网页版的"切模式"疑似通过 EQ 预设 cmd 22 实现：游戏预设值 257–260，音乐预设 0–169）。

**回包解析注意**：input report 固定 63 字节，帧在第一个 `0xEE` 处结束，其后为残留数据需忽略。
设备回包的 seq 是它自己的累加计数器，与主机发送的 seq 无关。

## 5. 指示灯（说明书 + 实测修正版）

| 灯 | 位置 | 说明 |
|---|---|---|
| 音乐模式灯 | 最左（1） | 音乐模式时常亮，颜色=当前 USB 流采样率：**≤48k 浅蓝、>48k 绿色**（44.1k 浅蓝、96k/192k 绿色均实测）；游戏模式下熄灭 |
| 游戏模式灯 | 左二（2） | 游戏模式时常亮，颜色规则同上；音乐模式下熄灭 |
| 7.1 灯 | 左三（3） | 7.1 开=浅蓝（**2 声道输入常亮 / 8 声道输入闪烁**）；7.1 关=熄灭 |
| 麦克风灯 | 最右（4） | 麦克风开=浅蓝，关=熄灭 |

**红色**：四个灯都**没有**红色工作状态。唯一出现红色的场景：同时按住 M 键+麦克风键约 1 秒恢复出厂设置时，**全部灯变红并保持 1 秒**，然后设备自动重启。

**颜色与说明书出入**：说明书称 "PCM>48kHz 亮黄色、DSD 亮绿色"，但实测 96k/192k 均为**绿色**（绿=Hi-Res 高清指示，飞傲全系惯例），黄色疑似仅 DSD（macOS 无法直接输出 DSD，未验证）或说明书有误。

**变色机制（实测结论）**：灯色跟随 USB 音频接口当前协商的采样率，与是否真在播放无关——
用 `mage-set-rate 146 96000` 把采样率设为 96k 后灯立即变绿，设回 48k 变蓝。
注意：macOS 播放高解析文件时会自动重采样到设备当前采样率（实测播放 96k 文件时实际流仍是 48k），
所以要触发灯色变化必须先设采样率，再播放。

**可控性**：总开关（cmd 6）可软件控制 ✓（实测全灭/恢复）；RGB 颜色不可控（cmd 51 无效果）✗；
采样率颜色联动可软件触发 ✓。飞傲网页版面板同样只有"指示灯开/关"，无颜色选项。

## 6. 工具集（本目录）

| 工具 | 用途 |
|---|---|
| `mage-keys` | 按键监听/拦截。`--learn --seconds N` 被动识别（免 root）；正常运行 seize 独占需 sudo，keymap 自定义动作 |
| `mage-hid-inspector` | 枚举 HID 接口、打印 Report Descriptor |
| `mage-led` | 厂商通道控制：`status` / `led on\|off` / `mic on\|off` / `71 on\|off` / `raw <cmd> [bytes]` |
| `mage-set-rate [devID] <rate>` | 查看/设置音频设备采样率（触发灯色变化） |
| `mage-play96k` | 临时切默认输出到 MAGE 播 96kHz 测试音后恢复 |
